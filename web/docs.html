Public API

Static JSON files, regenerated every hour. No key, no sign-up, no rate-limit server — CORS is open, so you can call it straight from a browser. Base path: /api/v1/.

curl -s https://YOUR-SITE/api/v1/state.json | jq '.data | {mood, tension_index}'

Response shape

Every response is an envelope with meta and data:

{
  "meta": { "api_version": "v1", "generated_at": "2026-10-11T12:00:00Z", "count": 300, ... },
  "data": [
    {
      "id": "3f1c0a9b2d4e5f60",
      "title": "Leaders sign regional trade accord",
      "url": "https://publisher.example/story",
      "summary": "Short excerpt from the feed…",
      "image": "https://…/thumb.jpg",
      "source": { "id": "bbc-world", "name": "BBC News – World" },
      "published_at": "2026-10-11T11:42:00Z",
      "fetched_at": "2026-10-11T12:00:00Z",
      "categories": ["deals", "economy", "diplomacy"],
      "regions": ["asia"],
      "tone": "deal"
    }
  ]
}

tone is one of deal, crisis, mixed, neutral.

Method

Articles come from public RSS/Atom feeds listed in config/sources.json. Categories and regions are assigned by transparent keyword rules in worldpulse/classify.py — no black-box model, so anyone can audit and improve them. The tension index is the share of crisis stories among crisis + deal stories over the last 24 hours (0 = all dealmaking, 100 = all crisis). It measures coverage, not ground truth.

Fair use

Only headlines, short excerpts and links are republished. Always link to url and credit source.name. Please cache responses — the data only changes hourly.
